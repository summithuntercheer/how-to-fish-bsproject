Download the latest archive from the button above

2. Select the required mods.
3. Click **Apply**.
4. Launch **How to Fish**.

# ⚒️Features
### Silent Aim:
- Aim stays in place, shots automatically hit the nearest target
- Hold Mouse4 — Activation
- Mode — Predict (trajectory + gravity) / Instant Hit (hitscan)
- FOV & Range — Field of view and distance sliders
- Hitbox Priority — Head / Body / Closest point
- Visible Check — Visibility verification
- Sticky Aim — Sticky aim
- Draw FOV / Draw Target Line — Display FOV and line to target
- Melee Silent Aimbot — Silent aim for melee combat
- Accuracy — Accuracy (0–100%)
- Target Filter — Both / Players / Mobs

### Weapon Config:

- No Recoil / No Spread — No recoil / no spread
- Auto Fire (hold) / Auto Melee (hold) — Auto-fire / auto-melee (hold)
- Infinite Ammo — Infinite ammunition
- Instant Reload — Instant reload
- Always Critical — Always critical hit
- Damage Multiplier — Damage multiplier (x1–x5)
- Melee Swing Speed — Melee attack speed (x1–x5)
- Fire Rate Multiplier — Rate of fire (x1–x5)

### Player:

- God Mode — God mode
- No Fall Damage — No fall damage
- No Sink (Infinite Breath) — Infinite breath (no drowning)
- Poison Immunity — Poison immunity
- Fire Immunity — Fire immunity

### Visual (ESP):

- Show Creatures — Show creatures (red markers)
- Show Players — Show players (yellow markers)
- Show Loose Items — Show loose items (green markers)
- Range — Range (20–500 m)

### Misc:

- Fast Reel — Fast reeling
- Auto Catch — Auto-catch
- Speed Boost — Speed boost (x1–x5)
- Unlock Boat + Radar — Unlock boat and radar (one-click)
- Item Silent — Item pickup prompt outside normal reach
- Reach Boost — Pickup range increase (x1–x5)
- Noclip — Toggle key N, adjustable speed, WASD + Space/Ctrl — free flight
